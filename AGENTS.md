# Regras e Diretrizes do Projeto AvaliaScan

## Versionamento do Painel Principal de Avaliações
- A cada alteração feita no sistema ou tarefa realizada, colocar no alto da tela do painel principal de avaliações a frase **Versão 01.01.01**, e acrescentar um a cada alteração feita (exemplo: `Versão 01.01.01`, `Versão 01.01.02`, `Versão 01.01.03`, etc.).
- Qualquer alteração realizada pelo usuário (criação de avaliação, edição de gabarito, exclusão, etc.) ou alteração de código pelo assistente deve refletir o incremento de versão no topo do painel principal de avaliações.
